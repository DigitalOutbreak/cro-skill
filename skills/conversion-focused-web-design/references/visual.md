# Compose the page around the decision

1. Put the real headline, strongest proof and primary action into a single column before choosing the desktop grid. Cover the logo and ask someone what they can do here. If the answer depends on the stock photograph, rewrite the heading.
2. Name three levels of attention. On a repair page the job and call action lead, coverage and opening hours support, and corporate details recede. Give one action per decision point the strongest fill. Secondary actions can be links with explicit destinations. Use weight, position and whitespace before enlarging every element.
3. Reuse the project's spacing tokens. For a new system try 4, 8, 12, 16, 24, 32, 48 and 64 CSS pixels as starting values. Place a field label 8px above its input and leave 24px before the next field. Compare the gaps visually. The label must belong to its input even when the error wraps.
4. Align the heading, copy and first action on a common edge. Limit reading width to roughly 55–75 characters for extended prose. Start body type around 1rem with 1.5 line height and tune for the actual face. Use a shorter line height for display text and check descenders and wrapping at text zoom. Size headings by role independently from semantic heading level.
5. Define color roles for text, surface, action, border, focus and feedback. Sample real foreground/background combinations, including text on photos. Pair status color with words or icons. Look at the page in grayscale. If every card looks equally urgent, simplify the supporting surfaces.
6. Let the subject dictate the image crop. Show repair work or a finished installation where it answers a buyer's question. Give the image intrinsic dimensions. On narrow screens keep the action reachable before a tall image, and verify the crop preserves the subject. Decorative images get an empty alt attribute.
7. Choose breakpoints where actual labels collide or a line becomes unreadable. Keep DOM and reading order sensible. Test a long city name, long translation, missing photo and a three-line CTA. Avoid fixed-height containers for text. Use visual separation by spacing or a surface shift before adding another border.

**Worked composition.** A design-build contractor's gallery can lead a project page because finish quality is the decision. Caption the image with verified scope and materials, then place “Discuss a similar project” beside it. A burst-pipe landing page has a different decision. Lead with coverage and the contact path, and move project photography below the immediate action.
