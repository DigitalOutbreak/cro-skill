# Evaluate the journey consistently

Score each dimension on evidence. **0** means absent, misleading or blocked. **1** means possible with material friction. **2** means the listed check passes. Use **U** for unverified and **N/A** with a reason. Report earned points / (2 × observed applicable dimensions) and coverage. If all are unknown, report unscored. Compare totals only across equivalent routes and coverage.

| Dimension | Evidence required for 2 |
| --- | --- |
| Intent and offer | Entry promise, visitor job, constraints and next action agree. |
| Visual hierarchy | Heading, proof and main action scan in order at narrow and wide widths without clipping. |
| Orientation | A deep-link visitor can identify location, explore relevant options and return. |
| Credibility | Material claims have support and major objections are answered where the decision occurs. |
| Action and recovery | Primary path completes, recovers from errors and confirms the actual next step. |
| Accessible interaction | Critical path works with keyboard, visible focus, accessible names, readable contrast and reflow. |
| Mobile delivery | Core content and action are usable under mobile constraints. Report measured performance and field coverage separately. |
| Outcome measurement | Eligible exposure and downstream outcome can be reconciled and deduplicated. |

Record route, state, viewport, evidence and confidence beside each grade. A screenshot can establish a visible omission. It cannot establish keyboard behavior, successful booking or page speed.

Block release for a broken primary action, a materially misleading promise, duplicate booking/payment or an inaccessible critical path. High priority means a common audience loses or struggles with a key task. Medium means recoverable friction or a material objection. Low means polish with little demonstrated impact. Broken tracking blocks an experiment readout even if the page can ship.

Example finding: a quote form erases project notes on a simulated 503. A successful retry gives action/recovery 1. Preserve the notes and verify exactly one request on retry. Financial impact is unknown until measured.
